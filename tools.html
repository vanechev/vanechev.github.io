Web App
BLS Video Annotation Tool
A browser-based tool for expert annotation of Basic Life Support (BLS) simulation videos against a predefined action set and OSCE marking rubric. Built for AI-enhanced feedback research in clinical education. Runs entirely in the browser — video files and annotations are never uploaded.
